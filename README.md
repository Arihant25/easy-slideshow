# easy-slideshow

A single-file, in-browser **Rapid Image Viewer** for flipping through hundreds of images as a fast slideshow. Nothing is uploaded — everything runs locally in your browser.

**Live:** https://arihant25.github.io/easy-slideshow/

## Features

- Drop a folder or pick hundreds of images
- 3-second countdown before the slideshow starts
- Adjustable frame duration (1 ms – 60 s)
- Thumbnail strip for jumping around
- Keyboard shortcuts: `Space` play/pause · `←`/`→` step · `Esc` toggle UI

## Use

Open [the live page](https://arihant25.github.io/easy-slideshow/), or clone and open `index.html` directly.
